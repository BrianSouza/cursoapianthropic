# Questionário: onboarding de produtores

> Para a gestora de Operações responder (pode ser em tópicos, com números aproximados). As respostas viram arquivo de conhecimento do Projeto: depois de preenchido, **suba este arquivo no Projeto**. A skill `growth-onboarding-produtor` usa estas respostas para ajustar o funil, as definições e as hipóteses.
>
> Tempo estimado: 20–30 minutos. Se não souber algo, escreva "não sei / quem sabe é [área]".

## 1. Etapas do onboarding hoje
1. Quais são os passos entre o produtor se cadastrar e fazer a primeira venda parcelada? (liste na ordem)
2. Em quais passos o produtor depende de alguém da empresa (aprovação, validação, suporte)?
3. Quanto tempo leva, em média, do cadastro até a primeira venda? E do cadastro até a integração pronta?
4. Que documentos/validações são exigidos? Algum costuma ser rejeitado com frequência?

## 2. Integração
5. Com quais plataformas de checkout/venda vocês integram? Qual % dos produtores usa cada uma (aproximado)?
6. Alguma integração é notoriamente mais difícil ou gera mais chamados?
7. Existe integração "em poucos cliques" (app/plugin) ou é sempre manual/técnica?
8. Depois de integrado, o produtor precisa ativar algo no checkout para a opção aparecer ao comprador?

## 3. Definições
9. O que vocês consideram **produtor ativo**? (ex.: ≥ 1 venda nos últimos 30 dias)
10. O que seria **produtor retido** aos 90 dias?
11. Existe uma classificação de porte/potencial do produtor? Como é calculada?
12. Qual a meta atual (se houver) para ativação de novos produtores?

## 4. Atendimento e comercial
13. Quem cuida do produtor novo? Todos recebem contato humano ou só alguns? Qual o critério?
14. Quantas pessoas atendem produtores novos? Quantos produtores novos entram por mês?
15. O time comercial participa até a primeira venda ou passa para outro time antes?
16. Há algum contato automático (e-mail, WhatsApp, notificação no painel) durante o onboarding? Quais?

## 5. Onde os produtores travam (percepção do time)
17. Quais são as 3 principais razões pelas quais um produtor cadastrado nunca vende?
18. Quais as dúvidas/chamados mais comuns nos primeiros 30 dias?
19. Algum perfil de produtor ativa muito melhor ou muito pior? (nicho, porte, plataforma, origem)
20. Já tentaram alguma ação para melhorar o onboarding? O que aconteceu?

## 6. Dados disponíveis
21. Quais eventos do produtor ficam registrados com data? (marque)
    - [ ] cadastro  - [ ] documentos enviados  - [ ] documentos aprovados  - [ ] integração concluída
    - [ ] opção ativada no checkout  - [ ] acesso ao painel  - [ ] venda aprovada  - [ ] repasse recebido
    - [ ] chamado de suporte  - [ ] contato do comercial/CS  - [ ] outros: ____
22. Onde ficam esses dados (sistema, planilha, banco) e quem consegue extrair?
23. É possível extrair sem dados pessoais (só ID do produtor)? Em que formato?
